# Поиск машин → Telegram

Программа раз в день ищет подходящие машины у дилеров Южной Флориды
(Auto.dev) и присылает интересные варианты вам в Telegram — фотографиями
и коротким описанием. Учится на ваших реакциях 👍/👎 под сообщениями.

## Что нужно один раз сделать перед запуском

1. **Установить Python 3.10 или новее.**
   - **Windows:** скачайте установщик с [python.org](https://www.python.org/downloads/)
     и запустите его. **Важно:** на первом экране установки обязательно
     поставьте галочку **"Add python.exe to PATH"** внизу окна — без неё
     команды ниже не заработают. Затем проверьте: откройте PowerShell
     (см. ниже, как это сделать) и наберите `python --version`.
   - **Mac/Linux:** проверьте в терминале командой `python3 --version`.
     Если не найдена — установите с [python.org](https://www.python.org/downloads/).

2. **Получить ключ Auto.dev** (тариф Starter) на сайте auto.dev и
   Telegram-бота через [@BotFather](https://t.me/BotFather) в Telegram
   (команда `/newbot`, в ответ дадут токен).

3. **Узнать свой TELEGRAM_CHAT_ID** — это номер вашего личного чата с
   ботом. Проще всего: напишите вашему боту любое сообщение (например,
   "привет"), затем откройте в браузере ссылку (вместо `<ТОКЕН>`
   подставьте токен бота):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   В открывшемся тексте найдите `"chat":{"id":ЧИСЛО` — это число и есть
   ваш chat_id.

4. **Заполнить файл с ключами.** В папке проекта найдите файл
   `.env.example`, сделайте его копию и переименуйте копию в `.env`
   (без `.example` на конце):
   - **Windows:** щёлкните правой кнопкой по `.env.example` в Проводнике
     → "Копировать", затем правой кнопкой в пустом месте папки →
     "Вставить". У копии измените имя на `.env`. Если Windows не
     показывает расширение файла (`.env.example` целиком), включите
     показ расширений: в Проводнике откройте вкладку "Вид" → поставьте
     галочку "Расширения имён файлов".
   - **Mac/Linux:** в терминале, в папке проекта: `cp .env.example .env`

   Откройте получившийся файл `.env` любым текстовым редактором (на
   Windows подойдёт обычный Блокнот — правой кнопкой по файлу →
   "Открыть с помощью" → "Блокнот") и впишите три значения:
   `AUTO_DEV_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
   Сохраните файл. Он никогда не попадёт в git — это специально, ключи
   должны оставаться только у вас на компьютере.

## Как запустить

### Windows

1. Откройте папку `car-finder` в Проводнике.
2. Щёлкните по адресной строке сверху (где написан путь к папке),
   сотрите путь, наберите `powershell` и нажмите Enter — откроется
   окно PowerShell уже в этой папке.
3. Наберите команду и нажмите Enter:
   ```
   .\run.bat
   ```
   (Также можно просто дважды щёлкнуть по файлу `run.bat` в Проводнике.)

Если Windows покажет предупреждение системы безопасности про
"неизвестного издателя" — это нормально для собственных скриптов,
можно продолжать ("Выполнить"/"Дополнительно → Выполнить в любом случае").

### Mac / Linux

Одна команда в папке проекта:

```
./run.sh
```

В обоих случаях команда сама создаст нужное окружение, поставит
необходимые библиотеки и запустит поиск. При первом запуске это может
занять минуту-две — не закрывайте окно, дождитесь надписи "Готово".

### Первый запуск — тестовый

По умолчанию в `.env` стоит `TEST_MODE=true` — программа найдёт и
пришлёт всего **3 машины**, чтобы вы посмотрели, то ли это, что нужно.
Когда всё устроит — откройте `.env`, поставьте `TEST_MODE=false` и
настройте расписание (см. ниже), чтобы программа сама запускалась
каждое утро.

## Как это работает (простыми словами)

- Программа делает **один поисковый запрос** к Auto.dev в день (с учётом
  подгрузки нескольких страниц результатов), плюс по одному короткому
  запросу за фото на каждую машину, которую реально отправляет (не на все
  найденные) — итого хорошо укладывается в лимит бесплатного тарифа
  (1000 запросов в месяц ≈ 30 в день).
- Ищет машины BMW, Mercedes-Benz, Infiniti, Lexus, Land Rover, 2019 года
  и новее, пробег до 85 000 миль, цена до $50 000, в радиусе 50 миль от
  индекса 33069.
- Из найденного оставляет только машины с "интересными" версиями
  (M Sport, AMG, F Sport, Red Sport 400, R-Dynamic/HSE/Autobiography и т.п.
  — по маркам, как в задании).
- Если у Auto.dev есть данные об истории машины — прямо пишет, есть ли в
  ней зафиксированная авария, и добавляет ссылку на Carfax, чтобы вы могли
  проверить сами. Если таких данных нет — сравнивает цену с похожими
  машинами и, если она заметно ниже, пишет предупреждение "проверить
  историю" (возможна авария или сложный статус документа) — это уже
  догадка, а не точный факт.
- Также пытается заметить признаки бывшей прокатной/перекупной машины
  (простая комплектация, большой пробег для года или много владельцев по
  данным истории) — тоже скорее подсказка, чем точный факт.
- Если в `.env` заполнить `DEALER_WHITELIST` (названия дилеров через
  запятую), программа будет показывать машины только от этих дилеров,
  все остальные — игнорировать. По умолчанию пусто — показываются машины
  от любых дилеров.
- Уже отправленные машины (по VIN) второй раз не присылает. Исключение —
  если у машины изменилась цена, тогда придёт короткое сообщение вида
  "цена упала с $30 000 до $28 000".
- Перед каждым поиском программа проверяет, ставили ли вы реакции 👍/👎
  под ранее присланными машинами, и запоминает это в файле
  `data/feedback.jsonl`. В следующий раз машины, похожие на те, что вам
  понравились, будут показаны выше, а похожие на те, что не понравились —
  ниже.

Все данные (база отправленных машин, файл с вашими оценками) хранятся
локально в папке `data/` и никуда не отправляются, кроме Telegram.

## Расписание (запуск каждое утро само)

### Windows — через "Планировщик заданий"

1. Нажмите Пуск, найдите и откройте программу **"Планировщик заданий"**
   (Task Scheduler).
2. Справа нажмите **"Создать простую задачу"**.
3. Имя — например, "Поиск машин". Далее.
4. Триггер — "Ежедневно". Далее, укажите время (например, 8:00 утра). Далее.
5. Действие — "Запустить программу". Далее.
6. В поле "Программа или сценарий" укажите полный путь до файла
   `run.bat` в папке проекта, например:
   `C:\Users\ВашеИмя\Desktop\car-finder\run.bat`
7. Готово. Теперь каждое утро в 8:00 Windows будет сама запускать поиск,
   даже если вы не открывали программу — главное, чтобы компьютер был
   включён и не спал в это время.

### Mac (launchd) или Linux (cron) — вариант попроще, через cron

Наберите в терминале `crontab -e` и добавьте строку (пример — запуск
каждый день в 8:00 утра; замените путь на настоящий путь до папки
проекта):

```
0 8 * * * /полный/путь/до/car-finder/run.sh >> /полный/путь/до/car-finder/data/run.log 2>&1
```

Узнать полный путь можно командой `pwd`, находясь в папке проекта.

Сохраните и закройте редактор — готово, теперь машина будет сама
проверять новые варианты каждое утро в 8:00.

## Если что-то работает не так

Названия параметров запроса и полей ответа Auto.dev сверены с их
официальной документацией. На всякий случай в программе всё равно есть
подстраховка:

- Если API вернёт ошибку — в терминале появится текст ошибки от
  Auto.dev, обычно он подсказывает, что не так.
- "Сырой" ответ API от последнего запуска сохраняется в
  `data/last_api_response.json` — если какое-то поле у машины пустое
  (например, всегда нет пробега), пришлите мне этот файл, и я
  быстро поправлю одну строчку в коде.

## Структура проекта

```
car_finder/
  config.py           — все настройки (параметры поиска, ключевые слова)
  auto_dev_client.py  — запросы к Auto.dev API
  scoring.py          — отбор "интересных" машин, сравнение цен, риски
  storage.py          — база отправленных машин (SQLite, файл data/car_finder.db)
  feedback.py         — чтение реакций 👍/👎, файл data/feedback.jsonl
  telegram_bot.py      — отправка сообщений/альбомов, чтение обновлений
  main.py              — всё вместе, точка запуска
run.sh                 — запуск одной командой (Mac/Linux)
run.bat                — запуск одной командой (Windows)
.env.example           — образец файла с ключами
```
